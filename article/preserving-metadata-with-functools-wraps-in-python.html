Preserving Metadata with functools.wraps in Python

When creating custom decorators in Python, functools.wraps serves as an essential utility to maintain the identity and documentation of the decorated function. Because decorators replace the original function with an internal wrapper, key attributes like the function's name and docstring are obscured by default. Applying functools.wraps to the wrapper function automatically copies the original function's metadata, ensuring that debugging tools, documentation generators, and introspection libraries continue to work seamlessly.

The Problem: Metadata Loss in Decorators

A Python decorator wraps an existing function with another function, adding behavior before or after execution. By default, this replacement means the original function loses its external identity.

Consider a standard decorator without functools.wraps:

def my_decorator(func):
    def wrapper(*args, **kwargs):
        """Wrapper docstring."""
        return func(*args, **kwargs)

    return wrapper


@my_decorator
def calculate_total(price, tax):
    """Calculates the total cost with tax."""
    return price + (price * tax)


print(calculate_total.__name__)  # Outputs: 'wrapper'
print(calculate_total.__doc__)  # Outputs: 'Wrapper docstring.'

In this scenario, calculate_total reports its name as wrapper and displays the wrapper's docstring rather than its own.

The Solution: Using functools.wraps

functools.wraps is a decorator provided by Python’s standard library that solves this issue by invoking functools.update_wrapper(). Applying @wraps(func) directly above the inner wrapper function ensures the original function's metadata is copied over to the wrapper.

from functools import wraps


def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        """Wrapper docstring."""
        return func(*args, **kwargs)

    return wrapper


@my_decorator
def calculate_total(price, tax):
    """Calculates the total cost with tax."""
    return price + (price * tax)


print(calculate_total.__name__)  # Outputs: 'calculate_total'
print(calculate_total.__doc__)  # Outputs: 'Calculates the total cost with tax.'

Key Attributes Preserved

By default, functools.wraps assigns the following attributes from the original function to the wrapper:

  • __name__: The defined name of the function.
  • __qualname__: The qualified name showing the full structural path of the function.
  • __doc__: The docstring describing the function.
  • __module__: The module in which the function was defined.
  • __annotations__: Any type hints declared in the function signature.

Additionally, wraps updates the wrapper's __dict__ with any custom attributes assigned to the original function and assigns the original function to the __wrapped__ attribute.

Practical Importance

Preserving metadata is critical for several routine programming tasks:

  1. Introspection and Signature Inspection: Tools such as Python’s built-in inspect module utilize __wrapped__ to extract parameter signatures and type hints accurately.
  2. Debugging and Logging: Error tracebacks display the actual function names rather than generic names like wrapper, speeding up the debugging process.
  3. Automated Documentation: Documentation frameworks like Sphinx rely on __doc__ and __name__ to generate accurate API documentation.
  4. Testing and Mocking: Testing frameworks often assert against function names and module paths, which fail when wrapped functions lose their original attributes.
