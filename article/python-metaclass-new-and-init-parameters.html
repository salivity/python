Python Metaclass new and init Parameters

In Python, metaclasses are used to customize the creation and initialization of class objects. When a class using a custom metaclass is defined, Python automatically invokes the metaclass's __new__ and __init__ methods, passing specific arguments that define the class's identity, hierarchy, and namespace. Understanding the parameters supplied to these two methods is essential for controlling class generation, modifying attributes dynamically, or validating class structures.

The Parameters of __new__

The __new__ method is responsible for actually creating and returning the class instance. Because it acts as a constructor for the class object, its first parameter represents the metaclass itself.

def __new__(mcs, name, bases, namespace, **kwargs):
    ...
  • mcs (or cls): The metaclass itself. This is analogous to cls in a standard class method.
  • name: A string representing the name of the class being created (e.g., 'MyClass').
  • bases: A tuple containing the base classes that the new class inherits from (e.g., (BaseClass,) or ()).
  • namespace (or dct / attrs): A dictionary or mapping containing the class's namespace, which includes all class attributes, methods, and functions defined in the class body.
  • **kwargs: Any additional keyword arguments passed in the class definition header (e.g., class MyClass(metaclass=MyMeta, custom_flag=True):).

Because __new__ is responsible for building the object, it must return a newly created class object, typically by calling super().__new__(mcs, name, bases, namespace).

The Parameters of __init__

The __init__ method initializes the class instance after it has already been created by __new__.

def __init__(cls, name, bases, namespace, **kwargs):
    ...
  • cls: The newly created class object (the instance of the metaclass returned by __new__).
  • name: A string representing the class name, identical to the name argument passed to __new__.
  • bases: The tuple of base classes, identical to the bases argument passed to __new__.
  • namespace (or dct / attrs): The class namespace dictionary, identical to the one supplied to __new__.
  • **kwargs: Any additional keyword arguments passed in the class definition header.

Unlike __new__, __init__ does not return anything; it simply performs post-creation configuration or validation on cls.

Key Difference: The First Argument

While both methods receive the same name, bases, namespace, and extra keyword arguments, their first arguments serve different roles:

Method First Parameter Role
__new__ mcs Refers to the metaclass. Used to instantiate the new class object.
__init__ cls Refers to the created class. Used to mutate or inspect the completed class.

Example

class Meta(type):
    def __new__(mcs, name, bases, namespace, **kwargs):
        print(f"__new__ called with:")
        print(f"  mcs: {mcs}")
        print(f"  name: {name}")
        print(f"  bases: {bases}")
        print(f"  namespace keys: {list(namespace.keys())}")
        print(f"  kwargs: {kwargs}")
        return super().__new__(mcs, name, bases, namespace)

    def __init__(cls, name, bases, namespace, **kwargs):
        print(f"__init__ called with:")
        print(f"  cls: {cls}")
        super().__init__(name, bases, namespace)

class Example(metaclass=Meta, extra_option=True):
    x = 42
    def greet(self):
        pass

When this script runs:

  1. Meta.__new__ receives mcs=Meta, name='Example', bases=(), namespace containing 'x' and 'greet', and kwargs={'extra_option': True}.
  2. Meta.__init__ receives cls=Example (the finished class) alongside the same name, bases, namespace, and kwargs.
