How to Pass Values to Python Generators with send

The Python generator .send() method transforms a standard data producer into a two-way communication channel, known as a coroutine. While standard iteration methods like next() only retrieve data from a generator, .send() allows an external caller to inject values directly into the generator's execution context while simultaneously advancing the execution to the next yield statement.

The Mechanism of .send()

In basic Python generators, the yield statement is used solely to emit values. However, yield is actually an expression that can evaluate to a value. When code invokes generator.send(value), the current yield expression inside the generator evaluates to whatever value was passed.

def accumulator():
    total = 0
    while True:
        # Execution pauses at yield, returns total, and receives value via .send()
        val = yield total
        if val is not None:
            total += val

In this example, the variable val receives the argument passed via .send().

Two-Way Communication in a Single Step

The .send() method performs two distinct operations in a single invocation:

  1. It injects the provided argument into the generator, fulfilling the expression at the paused yield.
  2. It resumes execution until the next yield statement (or termination), returning the value produced by that subsequent yield.

Because of this dual action, calling gen.send(10) both updates the internal state and retrieves the next yielded result immediately, functioning identically to next() but with custom input.

Priming the Generator

A generator cannot accept non-None values before it has started running. Execution must reach the first yield expression before the generator can receive input.

To prime an active generator, you must first execute either next(gen) or gen.send(None). Attempting to pass an actual value to an unstarted generator raises a TypeError.

gen = accumulator()

# Priming the generator to reach the first yield
next(gen)  # Returns 0

# Sending values into the generator
print(gen.send(10))  # val becomes 10; returns 10
print(gen.send(20))  # val becomes 20; returns 30

Key Use Cases

The .send() capability provides several architectural advantages:

  • Stateful Consumer Coroutines: It allows generators to maintain state across multiple inputs without relying on external class attributes or global variables.
  • Cooperative Multitasking: Early Python asynchronous frameworks leveraged .send() to yield control back to an event loop and receive completed I/O results when resumed.
  • Data Pipelines and Reset Signals: Consumers can send control signals (such as configuration updates or reset flags) down an active pipeline to alter processing behavior dynamically.
