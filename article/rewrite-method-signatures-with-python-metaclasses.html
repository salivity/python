Rewrite Method Signatures with Python Metaclasses

This article provides a technical guide on creating dynamic Python metaclasses that intercept class definitions and rewrite method signatures at runtime. By combining Python’s type construction hooks with the inspect module and the __signature__ dunder attribute, developers can inject parameters, alter default values, and enforce API contracts programmatically before class instantiation. The following sections break down the underlying mechanics, walk through an implementation, and address best practices for maintaining reflection and IDE compatibility.

Understanding the Mechanics

Metaclasses act as blueprints for classes. When Python encounters a class block, it gathers the class attributes into a namespace dictionary and passes them to the metaclass's __new__ or __init__ methods before creating the class object.

To rewrite a method signature dynamically, two actions must occur:

  1. Behavioral Modification: The runtime function must be wrapped or generated to accept the updated arguments without throwing a TypeError.
  2. Introspection Modification: Tools such as IDEs, documentation generators, and runtime validators rely on inspect.signature(). Python allows overriding signature introspection by attaching an inspect.Signature object directly to a callable's __signature__ attribute.

Constructing the Metaclass

To modify signatures dynamically, define a subclass of type and intercept methods within __new__.

The steps are:

  1. Inspect the attributes in the class namespace dictionary.
  2. Identify target callables (e.g., regular methods, excluding dunder methods).
  3. Use inspect.signature to extract existing parameters.
  4. Construct new inspect.Parameter objects and a new inspect.Signature.
  5. Wrap the original function to handle new arguments at runtime.
  6. Attach the new __signature__ to the wrapper function.

Here is a full implementation that dynamically injects a required tenant_id: str parameter to all public methods in the target class:

import inspect
from functools import wraps
from typing import Any, Callable

class SignatureRewriterMeta(type):
    def __new__(
        mcs, 
        name: str, 
        bases: tuple[type, ...], 
        namespace: dict[str, Any]
    ) -> type:
        for attr_name, attr_value in list(namespace.items()):
            # Only target non-dunder callable methods
            if callable(attr_value) and not attr_name.startswith("__"):
                namespace[attr_name] = mcs._inject_tenant_parameter(attr_value)

        return super().__new__(mcs, name, bases, namespace)

    @classmethod
    def _inject_tenant_parameter(mcs, func: Callable[..., Any]) -> Callable[..., Any]:
        original_sig = inspect.signature(func)
        params = list(original_sig.parameters.values())

        # Define the parameter to inject
        tenant_param = inspect.Parameter(
            name="tenant_id",
            kind=inspect.Parameter.POSITIONAL_OR_KEYWORD,
            default=inspect.Parameter.empty,
            annotation=str
        )

        # Insert after 'self' (the first positional parameter)
        if params and params[0].name == "self":
            new_params = [params[0], tenant_param] + params[1:]
        else:
            new_params = [tenant_param] + params

        new_signature = original_sig.replace(parameters=new_params)

        @wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            # Bind arguments against the rewritten signature to validate calls
            bound = new_signature.bind(*args, **kwargs)
            bound.apply_defaults()
            
            # Extract the injected argument so the underlying function doesn't fail
            tenant_id = bound.arguments.pop("tenant_id")
            
            # Context-specific logic using tenant_id can be executed here
            print(f"[Audit] Invoked {func.__name__} for tenant: {tenant_id}")

            # Call the original function without the injected parameter
            return func(*bound.args, **bound.kwargs)

        # Overwrite the introspectable signature
        wrapper.__signature__ = new_signature
        return wrapper

Applying and Testing the Metaclass

Classes declare this behavior using the metaclass keyword argument.

class DatabaseRepository(metaclass=SignatureRewriterMeta):
    def get_user(self, user_id: int) -> dict[str, Any]:
        return {"user_id": user_id, "status": "active"}

    def delete_user(self, user_id: int) -> bool:
        return True

Verify that the method signature has been rewritten using inspect:

repo = DatabaseRepository()

# Check signature via introspection
sig = inspect.signature(repo.get_user)
print("Updated Signature:", sig)
# Output: (tenant_id: str, user_id: int) -> dict[str, Any]

# Execution requires the dynamically added parameter
result = repo.get_user("tenant_abc", 42)
print("Execution Result:", result)
# Console output:
# [Audit] Invoked get_user for tenant: tenant_abc
# Execution Result: {'user_id': 42, 'status': 'active'}

Calling repo.get_user(42) will raise a TypeError directly from new_signature.bind() indicating that tenant_id is missing, mirroring standard Python behavior.

Key Considerations

  • Handling Class and Static Methods: Standard decorators like @classmethod and @staticmethod wrap functions in descriptor objects (classmethod, staticmethod). Check for these types explicitly during iteration, access the underlying function via attr_value.__func__, rewrite the signature, and re-wrap it in the corresponding descriptor.
  • Argument Mapping: When dynamic arguments are added, you must pop them from bound.arguments (or transform them) before invoking the original function, unless the target function accepts **kwargs.
  • Reflection Consistency: Setting __signature__ overrides what inspect.signature reports, but it does not change func.__code__.co_varnames. Libraries relying strictly on bytecode inspections rather than the inspect module might still read the original argument list.
