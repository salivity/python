Python AST FunctionDef Node Explained

Python's built-in ast module represents Python source code as an Abstract Syntax Tree, providing programmatic insight into code structure without executing it. When parsing standard function definitions, the parser constructs an ast.FunctionDef node. This article explores the anatomy of the ast.FunctionDef node, breaking down its primary attributes—such as function names, argument signatures, execution bodies, decorators, and return annotations—and demonstrates how to inspect and work with these nodes in Python.

The Structure of ast.FunctionDef

An ast.FunctionDef node is created whenever the AST parser encounters a standard def statement (asynchronous functions defined with async def use ast.AsyncFunctionDef instead). The node encapsulates all syntactic elements of the function declaration.

The primary attributes of an ast.FunctionDef instance are:

  • name: A string containing the name of the function.
  • args: An ast.arguments node that models all parameters, including positional, keyword-only, default values, *args, and **kwargs.
  • body: A list of AST statement nodes (such as ast.Assign, ast.Expr, ast.Return) representing the code executed inside the function.
  • decorator_list: A list of AST expression nodes representing decorators applied to the function, listed in the order they appear from top to bottom.
  • returns: An AST node representing the return type annotation (such as ast.Name or ast.Constant), or None if no return type is specified.
  • type_comment: An optional string containing a PEP 484 type comment, if present.
  • Positional attributes: Integers including lineno, col_offset, end_lineno, and end_col_offset, which track the exact location of the function definition in the source file.

Parsing a Function into an AST Node

To observe how Python generates an ast.FunctionDef, pass source code as a string to ast.parse():

import ast

code = """
@timer
def calculate_total(price: float, tax: float = 0.05) -> float:
    result = price * (1 + tax)
    return result
"""

tree = ast.parse(code)
func_node = tree.body[0]

print(type(func_node))
# Output: <class 'ast.FunctionDef'>

In this example, the root of the parsed AST is an ast.Module whose body list contains a single ast.FunctionDef node.

Examining FunctionDef Attributes

1. Function Name and Decorators

The name attribute is stored directly as a string, while decorator_list holds expression nodes:

print(func_node.name)
# Output: calculate_total

print([dec.id for dec in func_node.decorator_list if isinstance(dec, ast.Name)])
# Output: ['timer']

2. Parameters (args)

The args attribute does not hold plain strings; it references an ast.arguments node containing several sub-lists:

  • posonlyargs: Positional-only parameters.
  • args: Standard positional or keyword parameters, stored as ast.arg objects.
  • vararg: The *args parameter (as an ast.arg object), or None.
  • kwonlyargs: Keyword-only parameters.
  • kw_defaults: Default values for keyword-only arguments.
  • kwarg: The **kwargs parameter (as an ast.arg object), or None.
  • defaults: Expressions representing default argument values, mapped from right to left to the parameters in args.
for arg in func_node.args.args:
    annotation = arg.annotation.id if isinstance(arg.annotation, ast.Name) else None
    print(f"Arg: {arg.arg}, Type: {annotation}")
# Output:
# Arg: price, Type: float
# Arg: tax, Type: float

3. Return Annotations (returns)

If a return annotation exists, func_node.returns holds the corresponding expression node:

if isinstance(func_node.returns, ast.Name):
    print(f"Returns: {func_node.returns.id}")
# Output: Returns: float

4. Function Body

The body attribute contains a list of statements that constitute the function's internal execution block:

for stmt in func_node.body:
    print(type(stmt).__name__)
# Output:
# Assign
# Return

Traversing ast.FunctionDef with a NodeVisitor

To analyze or transform functions across larger codebases, subclass ast.NodeVisitor:

import ast

class FunctionInspector(ast.NodeVisitor):
    def visit_FunctionDef(self, node):
        print(f"Found function: {node.name} on line {node.lineno}")
        print(f"  Arguments: {[a.arg for a in node.args.args]}")
        print(f"  Decorators: {len(node.decorator_list)}")
        self.generic_visit(node)

codebase = """
def add(a, b):
    return a + b

def greet(name='World'):
    print('Hello, ' + name)
"""

inspector = FunctionInspector()
inspector.visit(ast.parse(codebase))

Using ast.FunctionDef, static analysis tools, linters, docstring generators, and refactoring frameworks can read, validate, and manipulate Python function declarations programmatically without executing the underlying source code.
