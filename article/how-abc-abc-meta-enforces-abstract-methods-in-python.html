How abc.ABCMeta Enforces Abstract Methods in Python

In Python, the abc module provides the framework for defining Abstract Base Classes (ABCs), ensuring that derived classes implement required interfaces before they can be instantiated. This article explains the internal mechanics of abc.ABCMeta, detailing how the @abstractmethod decorator flags functions, how ABCMeta collects these dependencies into the __abstractmethods__ attribute during class creation, and how Python intercepts instantiation attempts to raise a TypeError if any abstract methods remain unimplemented.

Marking Callables with @abstractmethod

The enforcement process begins at the function level. When you decorate a method using @abstractmethod, Python attaches a boolean attribute named __isabstractmethod__ to the function object and sets it to True.

from abc import abstractmethod

class Base:
    @abstractmethod
    def run(self):
        pass

print(Base.run.__isabstractmethod__)  # Outputs: True

The decorator does not prevent the method from being called or defined; its sole purpose is to serve as an identifiable metadata flag for the metaclass.

Aggregating Methods at Class Creation Time

ABCMeta is a metaclass derived from type. When any class using ABCMeta as its metaclass is defined, Python calls ABCMeta.__new__ to construct the class object.

During this step, ABCMeta evaluates the class being constructed and its inheritance hierarchy:

  1. Inheriting Parent Abstract Methods: It inspects all base classes and collects any methods present in their __abstractmethods__ sets.
  2. Checking Overrides: It checks the namespace of the newly defined class. If the subclass provides an implementation for an inherited abstract method—and that new implementation does not have __isabstractmethod__ = True—the method is removed from the collection of pending abstract methods.
  3. Registering New Abstract Methods: It scans the current class namespace for any newly defined methods flagged with __isabstractmethod__ = True and adds them to the collection.
  4. Setting __abstractmethods__: Finally, ABCMeta stores the resulting collection as a frozenset on the class attribute named __abstractmethods__.

If a subclass provides implementations for all abstract methods inherited from its parent, its __abstractmethods__ attribute is computed as an empty set. If any abstract methods remain unoverridden, they stay in this set.

Intercepting Object Instantiation

The actual enforcement—the error that prevents an incomplete class from being used—does not happen when the class is defined; it happens when the class is instantiated.

When you attempt to instantiate a class by calling MyClass(), Python invokes type.__call__, which calls the class's __new__ method (typically object.__new__).

At the C-API level (within typeobject.c and Python's internal _abc implementation), object.__new__ inspects the class's __abstractmethods__ attribute:

  • If __abstractmethods__ is empty: Instantiation proceeds normally, and a new instance is returned.
  • If __abstractmethods__ contains any items: Python halts instantiation immediately and raises a TypeError specifying the names of the missing methods.
from abc import ABCMeta, abstractmethod

class Action(metaclass=ABCMeta):
    @abstractmethod
    def execute(self):
        pass

class SubAction(Action):
    pass

# Class creation succeeds:
print(SubAction.__abstractmethods__)  # frozenset({'execute'})

# Instantiation fails:
# Raises: TypeError: Can't instantiate abstract class SubAction with abstract method execute
instance = SubAction()

By decoupling method tagging (@abstractmethod), dependency calculation (class creation in ABCMeta.__new__), and enforcement (instantiation time in object.__new__), Python allows abstract classes to be subclassed across multiple inheritance layers while guaranteeing that incomplete subclasses can never produce concrete instances.
