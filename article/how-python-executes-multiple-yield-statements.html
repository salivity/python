How Python Executes Multiple Yield Statements

Python executes generator functions containing multiple yield statements by maintaining an internal state machine that suspends and resumes execution across function calls. When a generator function is invoked, Python does not run its body immediately; instead, it returns a generator iterator. Each time the generator is requested to produce a value—typically using the built-in next() function or a for loop—the Python interpreter resumes execution directly after the last encountered yield statement, continues until it encounters the subsequent yield, produces that value, and pauses execution once again.

1. Creation of the Generator Object

When a function contains the yield keyword, Python marks it internally with a CO_GENERATOR flag during compilation. Calling this function does not execute any code inside its body. Instead, it constructs and returns a generator object wrapping a Python execution frame. This frame stores the local variables, the instruction pointer, and the evaluation stack.

2. The Execution and Suspension Cycle

The sequential execution of multiple yield statements follows a strict cycle managed by the generator's internal instruction pointer (f_lasti in the CPython implementation):

  1. First next() Call: The interpreter starts execution at the top of the function and runs ordinary statements sequentially until it hits the first yield expression. It evaluates the expression, suspends the function frame, freezes all local variables, and returns the yielded value to the caller.
  2. Subsequent next() Calls: The interpreter restores the execution frame. Execution resumes immediately after the previously executed yield statement. Python executes any intermediate logic (such as variable assignments, loops, or print statements) until it reaches the next yield statement in sequence. It then freezes the frame state again and returns the new value.
  3. Repeated Sequential Transitions: This freeze-and-resume behavior repeats for each subsequent yield statement in the order they appear in the control flow.

Code Demonstration

def multi_yield_generator():
    step = 1
    yield step  # Yields 1, then pauses

    step += 1
    yield step  # Resumes here, yields 2, then pauses

    step += 1
    yield step  # Resumes here, yields 3, then pauses


gen = multi_yield_generator()

print(next(gen))  # Output: 1
print(next(gen))  # Output: 2
print(next(gen))  # Output: 3

3. Exhaustion and Termination

Once the final yield statement has executed, the next invocation of next() resumes the function from that point. If the execution path reaches the end of the function body without hitting another yield—or if an explicit return statement is encountered—CPython raises a StopIteration exception. If the function returns a value via return value, that value is attached to the StopIteration exception instance (StopIteration.value).

For loops and iteration protocols automatically handle the StopIteration exception, safely terminating the iteration without crashing the program.
