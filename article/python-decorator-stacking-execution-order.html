Python Decorator Stacking Execution Order

When applying multiple decorators to a single function in Python, the order of execution depends on whether you are looking at the decorator definition phase or the call-time execution phase. Decorators are applied from the bottom up at the time the function is defined, but the resulting wrapper functions execute from the top down when the function is actually called. Understanding this two-step mechanism is essential for debugging and properly chaining decorators like authentication, caching, and logging.

Function Definition: Bottom-Up Application

When you stack multiple decorators above a function, Python treats the syntax as nested function calls.

Consider this standard syntax:

@decorator_one
@decorator_two
def target_function():
    pass

Behind the scenes, Python evaluates this from the bottom up (closest to the function first). It is functionally identical to:

target_function = decorator_one(decorator_two(target_function))

During definition:

  1. decorator_two is called first, taking target_function as its argument and returning a new wrapper function.
  2. decorator_one is called second, taking the wrapper returned by decorator_two as its argument.

Function Invocation: Top-Down Execution

Because decorators wrap functions layer by layer, calling the decorated function reverses the sequence. The outermost wrapper (from the top decorator) executes first, passes control down the stack, and processes the return values on the way back up.

Given this implementation:

def decorator_one(func):
    def wrapper():
        print("Decorator One: Before")
        func()
        print("Decorator One: After")
    return wrapper

def decorator_two(func):
    def wrapper():
        print("Decorator Two: Before")
        func()
        print("Decorator Two: After")
    return wrapper

@decorator_one
@decorator_two
def greet():
    print("Inside greet()")

greet()

The output will be:

Decorator One: Before
Decorator Two: Before
Inside greet()
Decorator Two: After
Decorator One: After

Summary of Execution Flow

  1. Definition Time (Inside-Out): Bottom to top. Python applies @decorator_two first to wrap the original function, then applies @decorator_one to wrap the result.
  2. Call Time (Outside-In): Top to bottom for entry, bottom to top for exit. The pre-call code in @decorator_one runs first, followed by @decorator_two, then the target function, followed by the post-call code of @decorator_two, and finally @decorator_one.
