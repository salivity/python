Inspecting Tasks with asyncio.all_tasks in Python

Python's asyncio.all_tasks() function allows developers to inspect all active, uncompleted asynchronous tasks associated with an event loop. This article covers how asyncio.all_tasks() operates internally, how it scopes tasks to a specific or running event loop, and how it can be utilized for real-time monitoring, debugging, and implementing graceful shutdowns in concurrent Python applications.

How asyncio.all_tasks() Operates

The function signature is asyncio.all_tasks(loop=None). When invoked without an explicit loop argument, it calls asyncio.get_running_loop() to target the event loop of the current OS thread. If no event loop is running and no loop is passed, it raises a RuntimeError.

Under the hood, the Python asyncio runtime maintains an internal collection of alive Task objects using a weakref.WeakSet. When a new Task instance is scheduled, it registers itself with this global or loop-level tracker. Because it relies on weak references, tasks that are garbage-collected do not leak memory simply by being tracked.

When asyncio.all_tasks() executes, it performs the following steps:

  1. Identifies the target event loop (either the passed argument or the active running loop).
  2. Traverses the internal set of tracked Task objects.
  3. Filters the tasks to retain only those whose bound loop matches the target loop (task.get_loop() is loop).
  4. Omits any tasks that have already completed execution or finished their cancellation cycle (task.done() returns True).
  5. Returns a standard Python set containing the matching Task references.

Code Example

The following example demonstrates how to call asyncio.all_tasks() to inspect concurrent operations:

import asyncio

async def worker(task_id: int):
    await asyncio.sleep(2)

async def monitor():
    # Allow workers to spin up
    await asyncio.sleep(0.1)
    
    # Retrieve all active tasks for the current running loop
    active_tasks = asyncio.all_tasks()
    print(f"Total active tasks detected: {len(active_tasks)}")
    
    for task in active_tasks:
        print(f"- Task Name: {task.get_name()}, Done: {task.done()}")

async def main():
    # Spawn multiple background workers
    t1 = asyncio.create_task(worker(1), name="Worker-1")
    t2 = asyncio.create_task(worker(2), name="Worker-2")
    m = asyncio.create_task(monitor(), name="Monitor")

    await asyncio.gather(t1, t2, m)

asyncio.run(main())

Self-Inclusion and Filtering

A critical behavioral detail of asyncio.all_tasks() is that it includes the task from which the function is called. Because the inspecting coroutine is itself an active task executing on the loop, it appears in the returned set.

To inspect only external worker tasks, filter out the current task using asyncio.current_task():

current = asyncio.current_task()
external_tasks = {t for t in asyncio.all_tasks() if t is not current}

Primary Use Cases

  • Graceful Application Teardown: During application shutdown (such as intercepting a SIGINT or SIGTERM signal), asyncio.all_tasks() retrieves remaining tasks so they can be explicitly cancelled using task.cancel(), followed by asyncio.gather(*tasks, return_exceptions=True) to allow them to clean up resources cleanly.
  • Leak Detection: Long-running services can periodically count active tasks to detect coroutines that fail to terminate due to unhandled deadlocks, unyielding network sockets, or forgotten background processes.
