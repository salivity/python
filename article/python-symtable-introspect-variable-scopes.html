Python symtable: Introspect Variable Scopes

Python's built-in symtable module provides direct access to the compiler’s internal symbol tables, allowing developers to statically analyze the scope and binding behavior of identifiers without executing the underlying source code. This article explains the primary functions of symtable, how it constructs hierarchical scope trees, and how to inspect whether variables are local, global, free, or assigned.

What is the symtable Module?

During compilation, Python parses source code into an Abstract Syntax Tree (AST) and builds a symbol table to determine the scope of every identifier (variables, functions, classes). The symtable module exposes this compilation phase to Python code.

Unlike runtime introspection tools like globals() or locals(), symtable operates entirely statically. It can analyze code that might have unmet runtime dependencies or destructive side effects without running it.

Core Entry Point: symtable.symtable()

The primary interface of the module is the symtable() factory function:

import symtable

table = symtable.symtable(code, filename, compile_type)
  • code: The Python source string to analyze.
  • filename: A string representing the file name (used for syntax error reporting).
  • compile_type: The kind of code: 'exec' (modules/scripts), 'eval' (single expressions), or 'single' (interactive statements).

The function returns a top-level SymbolTable instance representing the global or module-level scope.

The SymbolTable Interface

A SymbolTable object represents a distinct namespace block. It contains metadata about the block and provides methods to traverse nested scopes and inspect contained identifiers:

  • get_type(): Returns the scope type as a string: 'module', 'function', or 'class'.
  • get_name(): Returns the name of the block (e.g., 'top' for the module, or the function/class name).
  • get_symbols(): Returns a sequence of Symbol instances representing all identifiers declared or referenced in this scope.
  • get_children(): Returns a list of nested SymbolTable instances (such as inner functions or class definitions).
  • is_nested(): Returns True if the block is contained within an outer function or closure.

Inspecting Identifiers with Symbol Objects

Each identifier within a SymbolTable is represented by a Symbol instance. These objects provide boolean query methods that expose the variable’s scope rules:

  • is_local(): True if the variable is local to this scope.
  • is_global(): True if the identifier is declared global or belongs to the module scope.
  • is_nonlocal(): True if declared with the nonlocal statement.
  • is_free(): True if the variable is referenced in the block but defined in an enclosing scope (a closure variable), without being declared global.
  • is_assigned(): True if the identifier is assigned a value in this scope (e.g., assignment statement, loop target).
  • is_referenced(): True if the identifier is read or called in this scope.
  • is_parameter(): True if the identifier is a function argument.

Practical Example

The following script analyzes a function containing local, global, and closure variables:

import symtable

source_code = """
global_var = 10

def outer(param):
    local_var = 20
    global global_var
    
    def inner():
        nonlocal local_var
        return local_var + global_var + param
"""

top = symtable.symtable(source_code, "<string>", "exec")

# Access the 'outer' function scope
outer_func = [child for child in top.get_children() if child.get_name() == "outer"][0]

print(f"Scope: {outer_func.get_name()} ({outer_func.get_type()})")
for sym in outer_func.get_symbols():
    flags = []
    if sym.is_parameter(): flags.append("parameter")
    if sym.is_local(): flags.append("local")
    if sym.is_global(): flags.append("global")
    if sym.is_assigned(): flags.append("assigned")
    print(f" - {sym.get_name()}: {', '.join(flags)}")

# Access the 'inner' function scope
inner_func = outer_func.get_children()[0]
print(f"\nScope: {inner_func.get_name()} ({inner_func.get_type()})")
for sym in inner_func.get_symbols():
    flags = []
    if sym.is_free(): flags.append("free (enclosed)")
    if sym.is_global(): flags.append("global")
    if sym.is_referenced(): flags.append("referenced")
    print(f" - {sym.get_name()}: {', '.join(flags)}")

Output:

Scope: outer (function)
 - param: parameter, local, assigned
 - local_var: local, assigned
 - global_var: global
 - inner: local, assigned

Scope: inner (function)
 - local_var: free (enclosed), referenced
 - global_var: global, referenced
 - param: free (enclosed), referenced

Primary Use Cases

  1. Static Analysis and Linters: Identifying unused variables, unbound local variables, or accidental shadowing of outer variables.
  2. Refactoring Engines: Safely renaming identifiers by confirming scope boundaries without breaking name bindings.
  3. Security Audits: Checking if untrusted scripts attempt to access or modify specific global namespaces before running them in a restricted environment.
