Python dis.code_info: Inspect Code Object Metadata

The dis.code_info() function in Python's built-in dis (disassembler) module generates a formatted, human-readable string summarizing the metadata of a compiled code object. When Python executes source code, it first compiles it into bytecode wrapped inside a code object (types.CodeType), which contains critical execution instructions, variable counts, and scoping parameters. Instead of manually inspecting numerous internal attributes prefixed with co_, developers can pass a function, generator, method, or code object directly into dis.code_info() to instantly see a structured breakdown of how Python's virtual machine manages that code.

What dis.code_info() Does

When invoked, dis.code_info(x) first extracts the underlying code object from the provided target x. If x is already a code object, it uses it directly; if x is a function or method, it retrieves the object stored in the __code__ attribute. It then parses the internal fields of the code object and returns a multi-line formatted string.

Key Metadata Displayed

The output returned by dis.code_info() groups code attributes into specific structural details:

  • Name and Origin: Displays the name of the code block (co_name), the file path where it was defined (co_filename), and the line number where the definition begins (co_firstlineno).
  • Argument Counts: Shows total positional arguments (co_argcount), positional-only arguments (co_posonlyargcount), and keyword-only arguments (co_kwonlyargcount).
  • Locals and Stack Requirements: Reports the total number of local variables allocated (co_nlocals) and the maximum runtime evaluation stack depth needed by the virtual machine (co_stacksize).
  • Compiler Flags: Translates the raw bitmask integer co_flags into human-readable compiler flags, identifying features such as whether the code is optimized (OPTIMIZED), creates a new local namespace (NEWLOCALS), accepts *args (VARARGS) or **kwargs (VARKEYWORDS), or represents a generator or coroutine.
  • Constants and Identifiers: Lists all literal values loaded by bytecode (co_consts) and global or external names accessed within the scope (co_names).
  • Variable Collections: Categorizes variable names into parameters and local variables (co_varnames), closure cell variables (co_cellvars), and free variables resolved from enclosing scopes (co_freevars).

Practical Example

Consider the following function and how dis.code_info() summarizes its internal configuration:

import dis


def calculate_tax(subtotal: float, *, rate: float = 0.05) -> float:
    flat_fee = 2.0
    return (subtotal * rate) + flat_fee


print(dis.code_info(calculate_tax))

Running this code produces output structured like this:

Name:              calculate_tax
Filename:          example.py
Argument count:    1
Positional-only arguments: 0
Kw-only arguments: 1
Number of locals:  3
Stack size:        3
Flags:             OPTIMIZED, NEWLOCALS
Constants:
   0: None
   1: 2.0
Names:
Variable names:
   0: subtotal
   1: rate
   2: flat_fee

Why Use dis.code_info()

Directly inspecting co_ attributes requires memorizing low-level attribute names and decoding bitwise flag masks manually. dis.code_info() automates this interpretation, making it an essential diagnostic tool for:

  1. Debugging Closures and Scopes: Verifying whether a variable is properly classified as a local variable, a cell variable, or a free variable across nested functions.
  2. Performance Analysis: Checking stack depth requirements and total local variable slots to understand memory allocations per frame.
  3. Compiler Tooling and Metaprogramming: Verifying code dynamically compiled with the built-in compile() function to ensure parameters and flags match expectations before execution.
