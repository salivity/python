Implementing Subscripting in Custom Python Classes

Python's square bracket syntax ([]) provides a clean, unified interface for indexing, key lookup, and slicing across built-in types like lists and dictionaries. In custom classes, this functionality is enabled by implementing the special dunder methods __getitem__, __setitem__, and __delitem__. This guide explains how the Python interpreter intercepts subscript operations, passes arguments to these underlying methods, handles both discrete keys and slice objects, and allows you to build custom container types.

The Subscripting Protocol

When Python encounters square brackets applied to an object instance, it translates the syntax directly into a call to that object's corresponding magic method. Rather than relying on hardcoded type checks, Python uses duck typing via this subscripting protocol:

  • Retrieval (obj[key]) triggers obj.__getitem__(key)
  • Assignment (obj[key] = value) triggers obj.__setitem__(key, value)
  • Deletion (del obj[key]) triggers obj.__delitem__(key)

Under the hood, Python performs method lookup on the class itself rather than the instance namespace (i.e., type(obj).__getitem__(obj, key)), ensuring consistent evaluation and performance.

1. Accessing Data with __getitem__

The __getitem__(self, key) method accepts a single argument: the index, key, or slice passed inside the brackets.

class CustomList:
    def __init__(self, data):
        self._data = list(data)

    def __getitem__(self, index):
        return self._data[index]

cl = CustomList(["a", "b", "c"])
print(cl[1])  # Invokes cl.__getitem__(1) -> Output: 'b'

Handling Slices

When a range like cl[0:2] is passed, Python packages the indices into a slice object (slice(0, 2, None)) and delivers it directly to __getitem__. To properly support slicing, your method should handle slice instances:

def __getitem__(self, index):
    if isinstance(index, slice):
        return self._data[index.start:index.stop:index.step]
    return self._data[index]

If an invalid key or index is provided, the method should raise either an IndexError (for sequence-like objects) or a KeyError (for mapping-like objects).

2. Mutating Data with __setitem__

The __setitem__(self, key, value) method requires two arguments: the target index/key and the value being assigned. It is invoked when an assignment statement targets an index expression.

class CustomList:
    def __init__(self, data):
        self._data = list(data)

    def __setitem__(self, index, value):
        self._data[index] = value

cl = CustomList([10, 20, 30])
cl[0] = 99  # Invokes cl.__setitem__(0, 99)
print(cl._data)  # Output: [99, 20, 30]

Just like __getitem__, if slice syntax is used on the left side of the assignment (such as cl[0:2] = [1, 2]), the index parameter receives a slice object.

3. Removing Data with __delitem__

The __delitem__(self, key) method enables the del keyword on subscripted expressions. It accepts the target index or key and removes the corresponding value from the underlying storage.

class CustomList:
    def __init__(self, data):
        self._data = list(data)

    def __delitem__(self, index):
        del self._data[index]

cl = CustomList(["first", "second", "third"])
del cl[1]  # Invokes cl.__delitem__(1)
print(cl._data)  # Output: ['first', 'third']

If the item cannot be removed due to an invalid key or missing index, raise the appropriate IndexError or KeyError.

Complete Implementation Example

The following example combines all three methods into a custom key-value store that validates string keys and logs mutations:

class MonitoredDict:
    def __init__(self):
        self._store = {}

    def __getitem__(self, key):
        if not isinstance(key, str):
            raise TypeError("Keys must be strings.")
        return self._store[key]

    def __setitem__(self, key, value):
        if not isinstance(key, str):
            raise TypeError("Keys must be strings.")
        print(f"Setting {key!r} to {value!r}")
        self._store[key] = value

    def __delitem__(self, key):
        print(f"Deleting key {key!r}")
        del self._store[key]

# Usage
data = MonitoredDict()
data["user"] = "Alice"   # Output: Setting 'user' to 'Alice'
val = data["user"]       # Calls __getitem__
del data["user"]         # Output: Deleting key 'user'

Protocol Summary

Syntax Invoked Dunder Method Common Exceptions
obj[key] __getitem__(self, key) KeyError, IndexError, TypeError
obj[key] = value __setitem__(self, key, value) KeyError, IndexError, TypeError
del obj[key] __delitem__(self, key) KeyError, IndexError, TypeError

By implementing these three methods, your custom objects integrate seamlessly with Python's indexing syntax, creating predictable and idiomatic interfaces.
