Python enum.Flag Bitwise Operations Guide

Python's enum.Flag class provides a specialized enumeration type designed to support bitwise operations like union, intersection, symmetric difference, and inversion. Unlike standard Enum types, which represent distinct and mutually exclusive states, enum.Flag members can be combined using bitwise operators (|, &, ^, ~) to represent sets of options, permissions, or feature toggles. This article covers how enum.Flag implements these operations, how to define flag enumerations, and how Python handles combined flag instances.

Defining an enum.Flag

To use bitwise operations, members of an enum.Flag subclass should typically have integer values that are powers of two (\(1, 2, 4, 8, \dots\)). Python's enum.auto() helper automatically assigns successive powers of two when used inside an enum.Flag definition.

from enum import Flag, auto

class Permission(Flag):
    READ = auto()     # 1
    WRITE = auto()    # 2
    EXECUTE = auto()  # 4

How Bitwise Operations Work

enum.Flag overrides Python's standard bitwise magic methods—__or__, __and__, __xor__, and __invert__. When these operators are used between flag members, Python performs the operation on the underlying integer values and returns a new composite instance of the same Flag class.

Union (|)

The bitwise OR operator (|) creates a union of flags. The resulting member represents a combination where any bit set in either operand is set in the result.

read_write = Permission.READ | Permission.WRITE
print(read_write)  # Output: Permission.READ|WRITE
print(read_write.value)  # Output: 3

Intersection (&)

The bitwise AND operator (&) performs an intersection, retaining only the flags common to both operands. This is commonly used to mask or check for specific permissions.

user_perms = Permission.READ | Permission.WRITE
check_read = user_perms & Permission.READ
print(check_read)  # Output: Permission.READ

check_exec = user_perms & Permission.EXECUTE
print(check_exec)  # Output: Permission(0)

An empty intersection results in a pseudo-member with a value of 0. You can optionally define an explicit zero-value member (such as NONE = 0) to represent the empty set cleanly.

Symmetric Difference (^)

The bitwise XOR operator (^) toggles states. It returns flags that are set in one operand but not in both.

active_flags = Permission.READ | Permission.WRITE
toggled = active_flags ^ Permission.WRITE
print(toggled)  # Output: Permission.READ

Inversion (~)

The bitwise NOT operator (~) inverts a flag, returning all members of the enumeration except those present in the target flag. In Python 3.11 and later, ~ is constrained to the valid flags defined within the enumeration boundary rather than producing negative integers.

not_read = ~Permission.READ
print(not_read)  # Output: Permission.WRITE|EXECUTE

Membership Testing

enum.Flag instances support the in operator to verify whether a specific flag is part of a combined flag instance:

user_perms = Permission.READ | Permission.EXECUTE

print(Permission.READ in user_perms)     # Output: True
print(Permission.WRITE in user_perms)    # Output: False

Internal Representation and Deconstruction

When flags are combined, Python uses the underlying integer value to dynamically construct a compound member name separated by the pipe character (|). Flag instances are iterable, allowing easy inspection of individual components within a compound flag:

combined = Permission.READ | Permission.EXECUTE
for perm in combined:
    print(perm)
# Output:
# Permission.READ
# Permission.EXECUTE

This underlying bitmask structure enables high-performance flag checks while retaining the readability and type safety of Python enumerations.
