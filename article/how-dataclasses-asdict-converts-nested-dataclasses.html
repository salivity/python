How dataclasses.asdict() Converts Nested Dataclasses

Python's dataclasses.asdict() converts dataclass instances into standard Python dictionaries through a recursive traversal mechanism. This article breaks down how asdict() inspects object trees, recursively unpacks nested dataclass instances and standard collection types, uses copy.deepcopy on leaf values, and reconstructs complex nested data structures into plain dictionaries and lists.

The Core Traversal Mechanism: _asdict_inner()

Under the hood, dataclasses.asdict(obj, *, dict_factory=dict) acts as a public entry point to an internal recursive helper function named _asdict_inner().

The function inspects the data type of the passed object at every level of the object hierarchy and branches execution based on four distinct structural categories:

  1. Dataclass instances
  2. Standard mapping types (such as dict)
  3. Sequence and iterable collections (such as list and tuple)
  4. Atomic types and other objects

Step-by-Step Transformation Process

1. Detecting Nested Dataclasses

When _asdict_inner() encounters an object, it first checks whether it is a dataclass instance using _is_dataclass_instance(). If the check returns True, the function retrieves all defined fields using dataclasses.fields(obj).

Instead of reading the __dict__ attribute directly, it iterates through each Field definition and extracts the corresponding value using getattr(obj, f.name). It then passes each attribute back into _asdict_inner(). The resulting key-value pairs are instantiated using the specified dict_factory (which defaults to Python's standard dict).

2. Traversing Collections and Iterables

If an attribute is not a dataclass, _asdict_inner() checks if it is a container:

  • Dictionaries: If the object is a dictionary or an instance of dict, it recursively calls _asdict_inner() on every key and value, preserving dictionary-based nesting.
  • Tuples: If the object is an instance of a tuple (including namedtuple subclasses), it runs _asdict_inner() on each element and constructs a new tuple of the same type using type(obj)(...).
  • Lists: If the object is a list, it returns a new list populated by running _asdict_inner() on every item via a list comprehension.

This step ensures that if a dataclass contains a list of nested dataclasses (e.g., list[ChildData]), every nested instance within that collection is unpacked down to its primitive components.

3. Handling Leaf Values with Deepcopy

When _asdict_inner() encounters a value that is neither a dataclass instance nor a supported container type (such as integers, strings, floats, custom non-dataclass classes, or None), it does not simply assign the reference. Instead, it calls copy.deepcopy(obj).

This guarantees that the resulting dictionary is completely decoupled from the original dataclass instance, preventing mutations in the dictionary from altering the state of the original objects.

Practical Example

Consider the following nested structure:

from dataclasses import dataclass, asdict

@dataclass
class Address:
    city: str
    zip_code: str

@dataclass
class User:
    name: str
    addresses: list[Address]

user = User(
    name="Alice", 
    addresses=[Address(city="New York", zip_code="10001")]
)

result = asdict(user)

Execution proceeds in this order:

  1. asdict() calls _asdict_inner(user).
  2. user is recognized as a dataclass. It iterates over fields: name and addresses.
  3. name is a string; copy.deepcopy("Alice") returns "Alice".
  4. addresses is a list. It iterates over the items inside the list.
  5. The element Address(...) is recognized as a dataclass. It iterates over city and zip_code.
  6. city and zip_code are copied as primitives and converted into a dict via dict_factory.
  7. The reconstructed items are returned up the call stack, yielding:
{
    "name": "Alice",
    "addresses": [
        {
            "city": "New York", 
            "zip_code": "10001"
        }
    ]
}

Customizing Dictionary Creation

The dict_factory parameter allows developers to control how dictionaries are instantiated during the recursive process. Passing an alternative factory like collections.OrderedDict will cause every nested dataclass in the hierarchy to convert into that specific dictionary type instead of the standard dict.
