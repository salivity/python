Inspect.iscoroutinefunction in Python Explained

Python's inspect.iscoroutinefunction() function provides runtime introspection to determine whether a callable is an asynchronous coroutine function. As asynchronous programming has become a staple of modern Python development, libraries, frameworks, and middleware often need to handle both synchronous and asynchronous functions interchangeably. This utility inspects a callable's internal code flags to determine if it was declared using async def, allowing developers to write flexible dispatchers, decorators, and runtime handlers that safely route execution paths.

How inspect.iscoroutinefunction() Works

At its core, inspect.iscoroutinefunction(object) checks whether an object is a function created via the async def syntax. Under the hood, Python marks coroutine functions with a specific bit flag—CO_COROUTINE—in the function's underlying code object (__code__.co_flags).

When invoked, the function evaluates the target:

  • It returns True if the callable is a native coroutine function.
  • It returns False for standard synchronous functions, generator functions, and other non-coroutine callables.
import inspect

async def fetch_data():
    return {"status": "ok"}

def compute_metrics():
    return 42

print(inspect.iscoroutinefunction(fetch_data))       # Output: True
print(inspect.iscoroutinefunction(compute_metrics))  # Output: False

The Difference Between Coroutine Functions and Coroutines

A common source of confusion in Python asynchronous programming is the distinction between a coroutine function and a coroutine object:

  1. Coroutine Function: The definition itself (the factory), declared with async def. Calling it does not execute the function body; instead, it returns a coroutine object.
  2. Coroutine Object: The instance produced by invoking a coroutine function, which must be awaited or scheduled onto an event loop to run.

The inspect module provides dedicated checks for each state:

  • inspect.iscoroutinefunction(obj) verifies the callable definition.
  • inspect.iscoroutine(obj) verifies whether the object is an already instantiated coroutine awaiting execution.
coro_obj = fetch_data()

print(inspect.iscoroutinefunction(coro_obj))  # Output: False
print(inspect.iscoroutine(coro_obj))          # Output: True

# Clean up unawaited coroutine
coro_obj.close()

Common Use Cases

1. Dual-Path Execution (Sync and Async Dispatch)

Frameworks often accept user-defined callbacks that might be either synchronous or asynchronous. Checking the callable beforehand ensures that asynchronous callables are awaited while synchronous ones are invoked directly, avoiding unawaited coroutine runtime warnings.

import inspect

async def execute_callback(func, *args, **kwargs):
    if inspect.iscoroutinefunction(func):
        return await func(*args, **kwargs)
    return func(*args, **kwargs)

2. Decorator Adaptation

Decorators that wrap arbitrary functions must preserve the signature and execution style of the wrapped target. By inspecting the wrapped function before building the wrapper, the decorator can return an async def wrapper or a standard def wrapper dynamically.

Handling Wrapped Functions and Edge Cases

  • Decorators and functools.wraps: If a coroutine function is decorated using functools.wraps, inspect.iscoroutinefunction() automatically follows the __wrapped__ attribute chain in modern Python versions to detect the underlying coroutine function.
  • Callable Class Instances: Passing an instance of a class that implements an asynchronous __call__ method directly into inspect.iscoroutinefunction() returns False in Python versions prior to 3.12. In those cases, you must inspect the __call__ method directly (e.g., inspect.iscoroutinefunction(instance.__call__)) or use inspect.markcoroutinefunction() where applicable. Starting in Python 3.12, inspect.iscoroutinefunction() natively supports callable objects with an async def __call__ method.
