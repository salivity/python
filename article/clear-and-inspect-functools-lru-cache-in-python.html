Clear and Inspect functools.lru_cache in Python

Python's built-in functools.lru_cache decorator provides an efficient way to cache expensive function calls using a Least Recently Used (LRU) algorithm. To maintain and optimize an application using this decorator, developers often need to evaluate cache efficiency and reset stored results. This article demonstrates how to inspect runtime cache metrics using cache_info() and how to clear cached entries on demand using cache_clear().

Inspecting Cache Metrics with cache_info()

Functions wrapped with functools.lru_cache are augmented with a cache_info() method. Calling this method returns a named tuple displaying the current performance statistics of the cache:

  • hits: The number of times the function looked up an existing cached result.
  • misses: The number of times the function executed because the result was not in the cache.
  • maxsize: The maximum capacity configured for the cache (or None if unlimited).
  • currsize: The current number of items stored in the cache.
import functools

@functools.lru_cache(maxsize=128)
def fetch_user_data(user_id: int):
    # Simulated database or API call
    return {"user_id": user_id, "status": "active"}

# Generate some hits and misses
fetch_user_data(1)  # Miss
fetch_user_data(2)  # Miss
fetch_user_data(1)  # Hit
fetch_user_data(1)  # Hit

# Inspect the cache metrics
info = fetch_user_data.cache_info()
print(info)
# Output: CacheInfo(hits=2, misses=2, maxsize=128, currsize=2)

# Access individual attributes
hit_rate = info.hits / (info.hits + info.misses)
print(f"Hit Rate: {hit_rate:.2%}")

Inspecting Cache Configuration with cache_parameters()

In Python 3.9 and newer, decorated functions also expose cache_parameters(). This method returns a dictionary showing the initial configuration arguments without running the cache logic:

params = fetch_user_data.cache_parameters()
print(params)
# Output: {'maxsize': 128, 'typed': False}

Clearing the Cache with cache_clear()

When the underlying data changes or memory needs to be freed, you can invalidate all stored results using the cache_clear() method. This resets the cache storage and sets hits, misses, and currsize back to zero.

# Clear all cached results
fetch_user_data.cache_clear()

# Verify the cache has been reset
print(fetch_user_data.cache_info())
# Output: CacheInfo(hits=0, misses=0, maxsize=128, currsize=0)

Bypassing the Cache

If you need to execute the original, un-cached function directly without resetting the cache or recording a miss, access the underlying callable via the __wrapped__ attribute:

# Calls the original function directly without caching the result
raw_result = fetch_user_data.__wrapped__(1)
