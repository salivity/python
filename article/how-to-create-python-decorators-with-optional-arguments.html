How to Create Python Decorators With Optional Arguments

Writing a Python decorator that gracefully handles both bare usage (@decorator) and parameterized usage (@decorator(arg=val)) is a common design challenge. Standard decorators behave differently depending on whether arguments are passed: without arguments, the target function is passed directly to the decorator; with arguments, Python passes those arguments first, expecting a callable decorator in return. This guide demonstrates how to unify both behaviors cleanly and idiomatically using standard library tools, specifically functools.wraps and functools.partial.

The Problem: Call Signatures Differ

When you apply a decorator without parentheses:

@my_decorator
def example():
    pass

Python executes: example = my_decorator(example).

When you apply a decorator with parentheses:

@my_decorator(retries=3)
def example():
    pass

Python executes: example = my_decorator(retries=3)(example).

A naive decorator expects one pattern or the other, resulting in TypeError exceptions if the usage varies.

The Clean Solution: Using functools.partial

The most idiomatic way to support both forms is to set the function parameter default to None, use keyword-only syntax for configuration arguments, and return a functools.partial object when no function is initially supplied.

from functools import partial, wraps

def repeat(_func=None, *, times=1):
    if _func is None:
        return partial(repeat, times=times)

    @wraps(_func)
    def wrapper(*args, **kwargs):
        result = None
        for _ in range(times):
            result = _func(*args, **kwargs)
        return result

    return wrapper

How It Works

  1. Keyword-Only Arguments: Defining parameters after the asterisk (*, times=1) forces the user to specify decorator options as keyword arguments. This prevents ambiguity between passing a callable as a positional argument and passing options.
  2. Detection of Bare Invocation: When used as @repeat, Python passes the target function as the first positional argument (_func). Because _func is not None, the decorator wraps the function immediately using the default times=1.
  3. Detection of Parameterized Invocation: When called as @repeat(times=3), Python does not pass a function to _func, leaving it as None. The condition if _func is None: catches this and returns partial(repeat, times=3). Python then passes the target function into this partially applied function, properly completing the decoration cycle.
  4. Preserving Function Metadata: The @wraps(_func) decorator copies attributes such as __name__, __doc__, and type annotations from the original function to the wrapper function, ensuring introspection tools, debuggers, and linters behave correctly.

Practical Usage

This implementation works seamlessly in both scenarios:

# Used without parentheses (uses default times=1)
@repeat
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
# Output:
# Hello, Alice!


# Used with arguments
@repeat(times=3)
def ping():
    print("Ping")

ping()
# Output:
# Ping
# Ping
# Ping


# Used with empty parentheses (uses default times=1)
@repeat()
def say_bye():
    print("Goodbye!")

say_bye()
# Output:
# Goodbye!

This pattern eliminates the need for deeply nested wrapper functions or complex class-based decorators while remaining fully compatible with Python's typing and introspection systems.
