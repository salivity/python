Implementing Slicing in Python Custom Containers

To provide fully functional slicing support in a custom Python container, you must implement the sequence-related dunder (magic) methods to intercept and handle slice objects alongside normal integer indices. At minimum, a read-only container requires __getitem__ and __len__, while a fully mutable sequence capable of slice assignment and deletion also requires __setitem__ and __delitem__. This article outlines the specific methods needed, how to process slice instances properly, and provides a clear implementation example.

1. __getitem__(self, key)

The __getitem__ method handles element retrieval. When a user uses slice syntax like obj[start:stop:step], Python constructs a slice object and passes it as the key argument.

To support slicing:

  • Check whether key is an isinstance(key, slice) or an integer.
  • If it is a slice, extract the range and return a new instance of your container (or a list) containing the requested subset.
  • If it is an integer, return the single corresponding element.

2. __len__(self)

While not directly receiving slice arguments, __len__ is essential for resolving slice boundaries. The built-in slice object provides a method called indices(len), which converts negative indices, omitted boundaries (None), and step values into concrete (start, stop, step) integer tuples within the bounds of your container.

3. __setitem__(self, key, value)

For mutable containers, __setitem__ enables slice assignment (e.g., obj[1:4] = [10, 20, 30]).

To support slicing:

  • Check if key is a slice.
  • Ensure value is an iterable if assigning to an extended slice (a slice with a step other than 1).
  • Replace, insert, or resize the internal collection accordingly.

4. __delitem__(self, key)

The __delitem__ method supports slice deletion (e.g., del obj[1:3]).

To support slicing:

  • Check if key is a slice.
  • Remove all elements that match the resolved indices. When working with non-unit steps or dynamic sizes, deleting elements in reverse order prevents index shifting from altering the target deletion points.

Handling the slice Object with indices()

The standard way to process a slice inside these methods is using slice.indices(length). This method handles edge cases such as None values, out-of-bounds indices, and negative indexing:

start, stop, step = key.indices(len(self))

This returns a standardized (start, stop, step) tuple suitable for passing into the built-in range() function.

Complete Implementation Example

The following class demonstrates all four methods functioning together to provide complete slicing capabilities:

class SlicedList:
    def __init__(self, data=None):
        self._data = list(data) if data is not None else []

    def __len__(self):
        return len(self._data)

    def __getitem__(self, key):
        if isinstance(key, slice):
            start, stop, step = key.indices(len(self))
            return SlicedList([self._data[i] for i in range(start, stop, step)])
        elif isinstance(key, int):
            return self._data[key]
        raise TypeError("Invalid index type")

    def __setitem__(self, key, value):
        if isinstance(key, slice):
            start, stop, step = key.indices(len(self))
            if step == 1:
                self._data[start:stop] = value
            else:
                indices = list(range(start, stop, step))
                vals = list(value)
                if len(indices) != len(vals):
                    raise ValueError(f"Attempt to assign sequence of size {len(vals)} to extended slice of size {len(indices)}")
                for idx, v in zip(indices, vals):
                    self._data[idx] = v
        elif isinstance(key, int):
            self._data[key] = value
        else:
            raise TypeError("Invalid index type")

    def __delitem__(self, key):
        if isinstance(key, slice):
            start, stop, step = key.indices(len(self))
            # Delete in reverse order to keep earlier indices stable
            for i in reversed(range(start, stop, step)):
                del self._data[i]
        elif isinstance(key, int):
            del self._data[key]
        else:
            raise TypeError("Invalid index type")

    def __repr__(self):
        return f"{self.__class__.__name__}({self._data})"
