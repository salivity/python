What Setting PYTHONOPTIMIZE to 2 Does in Python

Setting the PYTHONOPTIMIZE environment variable to 2 instructs the Python interpreter to start in its highest level of built-in optimization mode. This configuration is identical to passing the -OO flag on the command line. When enabled, Python strips all assert statements, sets the internal __debug__ flag to False, and discards all docstrings from the compiled bytecode to reduce memory usage.

Primary Effects of PYTHONOPTIMIZE=2

1. Removal of Assert Statements

When Python compiles source code to bytecode under this setting, every assert statement is ignored and omitted from execution. Any logic, check, or expression contained within an assertion will not run.

2. Disabling the __debug__ Flag

The built-in constant __debug__ is permanently set to False. Any conditional code blocks guarded by if __debug__: are treated as dead code and completely stripped during bytecode compilation.

3. Complete Removal of Docstrings

Unlike setting PYTHONOPTIMIZE to 1 (which only removes assertions and __debug__ blocks), setting it to 2 strips all module, class, method, and function docstrings. The __doc__ attribute for all objects is set to None. This reduces the size of compiled bytecode files and slightly lowers the memory footprint of loaded modules.

4. Bytecode Caching Alterations

Python stores the optimized bytecode in the __pycache__ directory with a distinct suffix. Rather than standard .pyc files, Python writes .opt-2.pyc files. This ensures that optimized bytecode is kept separate from regular bytecode and does not interfere with standard executions.

Potential Risks and Side Effects

  • Broken Runtime Introspection: Code, libraries, or frameworks that depend on docstrings at runtime will fail. For example, command-line parsing libraries like docopt or documentation generators that inspect live objects will not function properly because __doc__ evaluates to None.
  • Security and Logic Vulnerabilities: If an application relies on assert statements to validate user input, verify permissions, or enforce data integrity, setting PYTHONOPTIMIZE=2 silently removes those safeguards, potentially introducing critical vulnerabilities.
  • Marginal Speed Gains: Despite the name, this setting does not noticeably increase CPU execution speed. The optimization primarily benefits disk space and memory footprint by discarding documentation text strings.
